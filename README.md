# 長浜城下町遺産マップ

長浜城下町遺産と、周辺の文化・歴史的な地物を地図上で閲覧できるWebサイトです。

## Webサイト

* https://armd-02.github.io/NagahamaJyoukamachi/

## ソースコード

* https://github.com/armd-02/NagahamaJyoukamachi

## 目的

* 「長浜城下町遺産」選定事業事務局／長浜城下町まちづくり勉強会と共同で開発
* 長浜城下町遺産のほか、文化・歴史的な地物も地図上に表示
* 長浜城下町遺産について: https://nagahama.net/jyoukamachi/

## ローカルでの確認

静的Webサイトのため、リポジトリのルートでHTTPサーバーを起動して確認できます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。設定や表示データは主に `data/`、マーカー画像は `icon/` にあります。
